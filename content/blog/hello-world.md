This is the first post on this site. I rebuilt my portfolio to be smaller and more honest — a few projects I actually care about, the internship that taught me the most, and now this: a place to write.

## What I'll write about

Mostly the things I'm learning while building:

- Full-stack engineering — sync engines, offline-first patterns, the unglamorous parts of shipping
- Machine learning in practice — what fine-tuning and evaluation look like when the dataset is messy
- Notes from research work on LLM agents, once the papers are out

## How this blog works

There's no CMS. Each post is a markdown file in the site's repository, rendered at build time. Publishing a post means pushing a commit — which means only I can write here, enforced by git itself rather than a login page. I like that.

More soon.
